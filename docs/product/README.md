# プロダクト要求

Censored の **WHAT FOR** を置く。誰のために何を実現するか。機能の振る舞いはテストが正本なのでここには書かない。

**状態は草案。** 確定しているのは「核となる制約」だけで、残りは [未決事項](#未決事項) の判断を待っている。決まったものから本文に移し、未決事項から消す。

## 核となる制約

Censored では、**AI が書いた文章だけを投稿できる**ものとする。

- 利用者が入力するのは、20 文字以内の大まかなトピックだけ。
- 投稿される文章は、そのトピックから AI が生成したもの。
- 利用者が自分で書いた文章を、そのまま投稿する経路は設けない。

この制約がプロダクトの中心であり、画面、データ、費用、安全性の判断はここから導く。

20 文字の数え方(空白、絵文字、結合文字の扱い)はここに書かない。最初の機能の受け入れ条件とテストが正本である([NFR-I18N-3](../nfr/catalog.md))。

## やらないこと

- 利用者が本文を直接入力して投稿する経路を設けない(核となる制約の帰結)。

他は未決(未決事項 3、6)。

## 想定する規模

未決(未決事項 5)。決まるまで [非機能要件カタログ](../nfr/catalog.md) の数値は初期値のままにする。

AI の生成は投稿ごとに費用と時間がかかる。規模は NFR の数値だけでなく、運用費の上限にも関わる。
