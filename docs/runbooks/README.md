# 運用手順書

**WHAT IF** を置く。何か起きたときに何をするか。本番環境ができたら追加する。

1 つの手順書の構成:

- **症状**: 何を見て気づくか
- **影響**: 誰の何が止まるか
- **対処**: そのまま実行できるコマンド
- **確認**: 復旧をどう確かめるか
- **報告**: 誰に伝えるか

障害のあとは手順書の更新に加えて、[不具合からの学習](../conventions/11-ai-native-flow.md) に従う。
