# 用語集

コードの識別子とテスト名はここの言葉に合わせる。同じものに別の名前を付けない。

## 開発プロセス

| 用語 | 意味 |
| --- | --- |
| ゲート | 通らないとマージできない検査 |
| 機械ゲート | `make` で判定できるゲート |
| レビューゲート | AI のレビュアーが判定し、人間が確認するゲート |
| ミュータント | テストの強さを測るためにコードへ加えた小さな変更 |
| 生存(survived) | ミュータントを入れてもテストが通ること。テストの穴を示す |
| 未到達(uncovered) | ミュータントの箇所をどのテストも実行していないこと |
| Port | application 層が定義する外部依存の抽象 |
| フェイク | Port のテスト用の実装 |

## プロダクト

| 用語 | 意味 |
| --- | --- |
| 書記素 | 見た目の 1 文字。拡張書記素クラスタ(UAX #29)で分割した 1 単位で、国旗の絵文字や結合文字を含む文字も 1 つに数える([ADR-0009](adr/0009-grapheme-counting.md)) |

トピック、候補、投稿、返信などの用語は、投稿の流れ([asuka1975/censored#2](https://github.com/asuka1975/censored/issues/2))の実装時に定義する。
