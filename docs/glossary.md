# 用語集

コードの識別子とテスト名はここの言葉に合わせる。同じものに別の名前を付けない。

## 開発プロセス

| 用語 | 意味 |
| --- | --- |
| ゲート | 通らないとマージできない検査 |
| 機械ゲート | `make` で判定できるゲート |
| レビューゲート | AI のレビュアーが判定し、人間が確認するゲート |
| ミュータント | テストの強さを測るためにコードへ加えた小さな変更 |
| 生存(survived) | ミュータントを入れてもテストが通ること。テストの穴を示す |
| 未到達(uncovered) | ミュータントの箇所をどのテストも実行していないこと |
| Port | application 層が定義する外部依存の抽象 |
| フェイク | Port のテスト用の実装 |

## プロダクト

未定義。投稿、タイムライン、フォローなどの用語を、最初の機能の設計時に定義する。
